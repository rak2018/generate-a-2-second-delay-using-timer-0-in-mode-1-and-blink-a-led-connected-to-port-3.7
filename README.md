# generate-a-2-second-delay-using-timer-0-in-mode-1-and-blink-a-led-connected-to-port-3.7
# Aim
To write an assembly language program to generate a square wave on port pin P3.7 using Timer 0 in Mode 1 of the 8051 microcontroller and observe the waveform using the Logic Analyzer in Keil.
# Apparatus Required:

Keil µVision IDE (software simulator)

8051 Microcontroller (AT89C51/52)

Proteus Design Suite (for simulation, optional)

Oscilloscope / Logic Analyzer (in software)

# Theory:

Timers in the 8051 microcontroller are used to generate accurate time delays or periodic events.

The 8051 has two timers: Timer 0 and Timer 1.

Each timer can operate in different modes.

Mode 1 is a 16-bit timer mode — the timer counts from the initial value loaded into THx and TLx registers up to FFFFH.

On overflow, the TFx flag is set.

In this program:

Timer 0 is used to create a time delay.

After each overflow, bit P3.7 is toggled to produce a square wave.

The frequency of the square wave depends on the delay generated by the timer and the crystal frequency (typically 12 MHz).

# Program
ORG 0000H

MAIN:
    MOV TMOD, #01H      
    CLR P3.7              

AGAIN:
    MOV TH0, #0B1H         
    MOV TL0, #0E0H
    SETB TR0              

WAIT:
    JNB TF0, WAIT       
    CLR TR0                
    CLR TF0                
    CPL P3.7              
    SJMP AGAIN            
END

# Result

The program successfully generates a square waveform on pin P3.7.

The waveform observed on the logic analyzer alternates between logic HIGH (5V) and LOW (0V) at regular intervals.

The frequency of the square wave depends on the values loaded into TH0 and TL0.
